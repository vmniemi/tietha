Application Security
Application Blacklisting and Whitelisting

• Limiting access to potential threats
by creating lists of prohibited
applications is known as
blacklisting.

• Application blacklists can dictate
which user applications are not
permitted to run on a computer.
• Whitelists specify which programs
are allowed to run.

• In this way, known vulnerable
applications can be prevented from
creating vulnerabilities on network
hosts.
